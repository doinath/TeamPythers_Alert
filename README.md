# ALERT: Assistance Link for Emergency Response & Tracking

### Project Overview 

ALERT is an academic programming project developed for the CSIT327: Information Management 2 course. Its primary goal is to implement a robust, data-driven system designed to streamline and improve the efficiency of emergency response and resource tracking operations.

The system focuses on managing crucial, time-sensitive information, ensuring secure access, and providing a clean, functional interface for administrative review and real-time incident management. The ultimate goal is to connect citizens with emergency services, facilitate rapid dispatch, and manage resource allocation efficiently.
